## 📱 About the App

**ShahnAk** is a comprehensive mobile application designed for Sudanese gamers to:
- 🎮 Recharge popular games (Free Fire, PUBG Mobile, Roblox, Mobile Legends, Call of Duty Mobile)
- 🔥 Buy and sell Free Fire accounts
- 🛒 Manage orders and payments
- 💳 Secure bank transfer payments
- 📤 Upload payment proofs
- 🔔 Receive order status notifications
- 💬 Direct WhatsApp support

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/azdan2009/ShahnAk.git
cd ShahnAk
```

### 2. Install Dependencies
```bash
flutter pub get
```

### 3. Setup Firebase (.env file)
- Create `.env` file in the project root
- Add your Firebase credentials (see below)

### 4. Run the App
```bash
flutter run
```

### 5. Build for Production
```bash
# Android APK
flutter build apk --release

# iOS IPA
flutter build ios --release
```
